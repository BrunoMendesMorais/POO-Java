# PROGRAMAÇÃO ORIENTADA A OBJETOS - JAVA

Este Repositório foi desenvolvido para a disciplina de Programação Orientada a Objetos, com o objetivo de aplicar na prática os principais conceitos relacionados ao paradigma de orientação a objetos.

Aqui se encontram todos os projetos desenvolvidos e sugeridos ao decorrer da matéria

## Conceitos de Programação Orientada a Objetos

Durante o desenvolvimento do projeto foram utilizados os seguintes conceitos:

* **Classes e objetos:** utilizados para representar as entidades do sistema.
* **Encapsulamento:** utilizado para controlar o acesso aos atributos e métodos das classes.
* **Herança:** utilizada para permitir o reaproveitamento de características entre classes relacionadas.
* **Polimorfismo:** utilizado para permitir diferentes comportamentos para objetos relacionados.
* **Abstração:** utilizada para representar apenas as características relevantes de cada entidade.
